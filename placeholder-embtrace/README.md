# embtrace is now Jochwacht

This name was reserved by [Innomatica GmbH](https://jochwacht.dev) for the
product family now called **Jochwacht**. The name changed because `embtrace`
collided with a registered trademark; the tools and their licences are
unchanged.

Looking for the free **CRA Readiness Check**? The open-source collector is
published as [`jochwacht-sbom`](https://pypi.org/project/jochwacht-sbom/):

```bash
pipx install jochwacht-sbom
```

This package reserves a name and contains no code. It receives no further
releases. Learn more at <https://jochwacht.dev>.
